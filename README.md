# 【WBX0513的聊天服务器™】

---

## 简介：
**Python 聊天系统，当前版本1.5.1，发布于【2026/09/17】。**

- 服务器：直接使用即可。
- 客户端：直接使用即可（先确保服务器打开）。

---

## 更新日志：

**1.5.1：**
- 现在文件可以直接拖入到客户端窗口了。

**1.5.0：**
- 加入了发送文件功能，一次最多发送 20MB 的文件，服务器缓存最多 200MB。
- 1.5.0及以后的服务器不再完全支持1.4.4及以下的客户端了。

**1.4.4：**
- 优化了管理员的指令体验。
- 新增命令 `unban user` 解除封禁。
- 新增命令 `banip`，有两种模式。模式1：`banip usermode user`，为封禁用户 `user` 所在的IP；模式2：`banip ipmode ip`，为直接封禁 `ip` 所在的IP。
- 新增命令 `unbanip`，有两种模式。模式1：`unbanip usermode user`，为解封用户 `user` 所在的IP；模式2：`unbanip ipmode ip`，为直接解封 `ip` 所在的IP。
- 新增命令 `admin`，有两种模式。模式1：`admin new user`，为添加 `user` 为管理员；模式2：`admin cancel user`，为取消 `user` 的管理员权限。这条命令需要经过服主的同意才能生效。
- 新增命令 `close` 关闭服务器。这条命令需要经过服主的同意才能生效。

**1.4.3：**
- 优化了服务器成员列表，封禁列表，IP封禁列表的更新逻辑。
- 当有人加入，被踢出/拉黑，封禁IP时自动刷新列表。
- 普通刷新时间为10秒。
- 加入手动刷新按钮。

**1.4.2：**
- 优化Emoji表情面板的UI逻辑。
- 现在Emoji表情面板可以完整显示所有表情了。

**1.4.1：**
- 服务器保存消息功能又加回来了。

**1.4.0：**
- 加入设置管理员功能。
- 新增命令 `kick user` 踢出 `user`。
- 新增命令 `ban user` 封禁 `user`。
- 由于某些事情，服务器保存消息功能暂时消失。

**1.3.2：**
